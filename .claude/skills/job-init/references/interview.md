# 访谈清单与候选项

SKILL.md 里的每一步要问什么、给哪些选项，都在这里。

## 搜索条件的选项（AskUserQuestion 用）

| 问题 | 选项 | 落到哪 |
| --- | --- | --- |
| 只看哪个城市？ | 北京 / 上海 / 深圳 / 杭州（其他让用户填） | `search.address` |
| 薪资门槛（年薪） | 100 万 / 80 万 / 60 万 / 不限 | `search.salary_kind` + `salary_floor`（单位元） |
| 要不要按学历过滤？ | 不过滤（推荐）/ 本科及以上 / 硕士及以上 | `search.edu_level` |
| 每个关键词翻几页？ | 6 页（取满上限，推荐）/ 3 页（快速试跑） | `search.max_pages` |

薪资门槛换算：年薪 100 万 = `salary_floor = 1000000`。
`salary_kind` 只能是 `年薪` 或 `月薪`；填了 floor/cap 就必须给 kind，否则配置校验会报错。

`edu_level` 合法取值：初中及以下 / 中专中技 / 高中 / 大专 / 本科 / 硕士 / 博士 / MBA·EMBA。
`work_experience` 合法取值：应届毕业生 / 1年以内 / 1-3年 / 3-5年 / 5-10年 / 10年以上。
**这两项是服务端强过滤**，填了就会把「学历不限」的岗位一起筛掉，多数情况建议留空。

## 关键词候选（按赛道）

按用户说的方向挑 4–8 个，写成 `[[search.groups]]`。宁少勿滥：
每个关键词最多返回 120 条，关键词太多只会让采集时间变长。

- **AI 应用 / Agent**：`AI Agent`、`大模型`、`AI应用`、`AI平台`、`LLM`、`AI工程`、
  `Agent工程师`、`大模型应用`、`Copilot`、`RAG`、`智能体`
- **AI 算法 / 训练**：`大模型算法`、`预训练`、`后训练`、`多模态`、`强化学习`、`AI Infra`、`推理优化`
- **Web3 / 区块链**：`区块链`、`智能合约`、`Web3`、`Solidity`、`DeFi`、`钱包`、`交易所`
- **安全**：`安全研究`、`安全专家`、`AI安全`、`大模型安全`、`智能合约安全`、`区块链安全`、`漏洞`
- **后端 / 架构**：`后端架构师`、`后端技术专家`、`技术专家`、`基础架构`、`平台开发`

组的 `track` 只能是 `AI` / `Web3` / `安全` / `后端` 四个值之一（拼错会直接报错）。
track 不只是分组标签，它是分类兜底的依据：职位名看不出赛道时，
按「关键词所属赛道 + JD 正文信号词」判定。

## 简历访谈清单（从零写时用）

一段一段问，问完一段就写进 profile 的 `resume.md`，不要攒到最后。

1. **基本信息**：姓名、联系方式（电话 / 邮箱 / 微信）、GitHub / 博客 / 公众号
2. **个人简介**：出生年份、学历背景（学校 + 本硕 + 专业）、总年限、覆盖过的领域、当前聚焦方向
3. **核心能力**：分 4–6 个方向，每个方向追问「做到过什么规模 / 什么结果」
4. **每段工作经历**：公司、岗位、起止时间、是否带人（几人、实线还是虚线）
5. **每段经历下的项目**：背景（产品是什么 + 技术栈）、你的职责边界、亮点
   - 亮点必须能被追问细节：技术决策 + 可量化结果（规模、性能、金额、用户数、TVL）
   - 追问一句「这件事最难的地方在哪」，答案往往就是最该写进简历的那句
6. **教育背景**：学校、学历、专业、时间；竞赛 / 论文 / 社团创办等单独列
7. **对外输出**：文章、演讲、开源项目、专利、获奖

## 求职偏好访谈清单

分批问，每批 3–4 个问题。

**第一批 · 硬约束**
- Base 地只看哪里？能不能接受远程 / 出差 / 外地？有没有家庭因素需要考虑？
- 明确不看的岗位类型有哪些？

**第二批 · 岗位与薪资**
- 优先想投什么方向？还能考虑什么？
- 公司阶段（大厂 / 成长期 / 初创）有偏好吗？管理岗还是纯技术岗？
- 目标包裹多少（**统一按税前**，JD 标的就是税前）？现金与期权怎么构成？什么条件下可以放宽？

**第三批 · 背景（HR 一定会问的）**
- 为什么现在看机会？
- 当前职级？带几个人（实线 / 虚线）？
- 绩效情况如何？有低绩效或空窗期吗？
- 到岗时间？现在在职吗？离职流程多久？
- 出生年月、性别、婚育情况？（说明：猎聘和 HR 都会问，写在这里省得每次回忆）

**第四批 · 面试口径（可选但值得写）**
- 「为什么看机会」对外统一怎么说？
- 低绩效 / 空窗期怎么解释？
- 薪资谈判的底线是多少？什么条件下可以下探？

敏感项开场先说清楚：**这些只存在本地、不进版本库**，用途是生成报告建议和准备面试问答。
用户不愿意答就写「未填」，不要追问，也不要在后面的对话里再提。

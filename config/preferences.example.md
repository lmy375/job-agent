# 求职偏好

> 程序不解析这份文件，它是给你自己和 Claude 看的：写报告「给我的建议」章节、
> 从库里挑岗位、准备面试问答时都以它为准。
> 所以**有一说一**，包括不方便写进简历的部分（低绩效、薪资构成、家庭约束）。
> 这份文件不进版本库。

## 硬约束（不满足就不投）

- **Base 地**：<只看哪些城市？能不能远程？有没有家庭因素限制（定居、家人、小孩）？>
- **不看的岗位**：<明确排除的类型，写具体一点，筛岗时直接照它过滤>
- **其他红线**：<例：不接受长期出差 / 不接受外包 / 需要弹性工作>

## 期望岗位

- **优先方向**：<最想投的一到两个方向>
- **也可以考虑**：<次优选项>
- **公司阶段与规模**：<大厂 / 成长期 / 初创，有偏好就写>
- **管理岗 or 纯技术岗**：<以及过去带过几个人、实线还是虚线>

## 期望薪资

- **目标包裹**：<一个数字 + 单位。例：税前年薪 XX 万 ＋ 期权>
- **构成与口径**：<现金 / 期权比例，税前还是税后——两边搞混会差出 50%>
- **可放宽的条件**：<什么情况下可以让步：业务方向、团队、期权比例……>
- **与搜索门槛的关系**：`config.toml` 里的 `search.salary_floor` 应当**低于**目标包裹。
  猎聘按薪资**区间重叠**过滤，且 JD 标的是税前月薪 × 月数；
  门槛设成目标值会把大量实际能谈到位的岗位挡在外面。

## 现状与背景（HR 和猎头一定会问）

- **看机会原因**：<对外能说的那版；负面表述留到「面试口径」里再处理>
- **当前职级与带人情况**：<职级、带几个人、最近有没有变化>
- **绩效情况**：<近几次评级；有低绩效或空窗期就写清，面试一定会被问>
- **到岗时间**：<在职还是待业；提离职了吗；离职流程多久>
- **基本信息**：<出生年月 / 性别 / 婚育——猎聘和 HR 都会问，写在这里省得每次回忆>

## 面试口径（可选，但很值得提前写）

- **「为什么看机会」的正式说法**：<对外统一口径，别每次临场编>
- **低绩效 / 空窗期怎么解释**：<一句话讲清背景与你的应对，不辩解>
- **薪资谈判的底线与话术**：<能接受的下限、什么条件下可以下探>

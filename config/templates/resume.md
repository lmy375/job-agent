> 写的时候记住两件事（都是从 2000+ 份百万级 JD 里读出来的）：
>
> 1. **用市场的词，不用公司内部的词。** 同一件事，JD 里怎么写你就怎么写
>    （「AI 产品研发」→「大模型应用工程 / Agent 工程化」）。
>    做完可以用 `uv run python scripts/track_stats.py` 看目标赛道的高频词，逐个比对。
> 2. **按「建制者」组织，而不是「资深工程师」。** 每段经历都补上
>    scope（带几个人 / 服务多少用户 / 多大资产规模）、职责边界、可量化结果。
>    「我做了什么技术」不如「我建成了什么、规模多大」。
